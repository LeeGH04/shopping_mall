**프로젝트 구조**

src/
├── assets/               # 정적 파일 (이미지, 폰트 등)
├── components/           # 재사용 가능한 UI 컴포넌트 (예: Header, Footer)
├── pages/                # 페이지 단위 컴포넌트 (예: Home, Product, Cart)
├── hooks/                # 커스텀 React Hook
├── utils/                # 유틸리티 함수 및 API 로직
├── styles/               # 전역 스타일 및 CSS 변수
├── App.jsx               # 메인 애플리케이션 컴포넌트
├── index.js              # 진입점

**설치 및 실행**

1. cd shopping-mall-frontend
2. npm install 
3. npm start


빌드 및 배포
1.	빌드 실행: npm run build 
2. build/ 폴더의 파일을 배포 서버에 업로드합니다.
